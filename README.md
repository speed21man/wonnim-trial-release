# 원님 재판

조선 시대를 배경으로 한 시나리오 중심 추리 게임 프로토타입입니다.

Godot과 JSON 기반 시나리오 데이터를 활용하여
장면, 대사, 조사, 단서, 의심도와 추론 과정을 구성했습니다.

## 주요 특징

- 비주얼노벨 방식의 대화와 포트레이트 연출
- 조사 및 인물 대화 시스템
- 단서 획득과 인물별 의심도 누적
- 숫자 범위 기반 추론 시스템
- JSON 기반 시나리오 구조
- 다국어 번역을 고려한 텍스트 ID 구조
- 현재 장면과 데이터 흐름을 확인할 수 있는 개발 모드

## 다운로드

오른쪽의 **Releases**에서 최신 Windows 버전을 다운로드할 수 있습니다.

## 실행 방법

1. `WonnimTrial_v0.1.1_windows.exe`를 실행합니다.

## 개발 상태

현재 포트폴리오 목적으로 제작 중인 프로토타입입니다.

게임 소스와 제작 리소스는 비공개로 관리하고 있으며,
이 저장소는 실행 파일 배포와 프로젝트 소개를 목적으로 사용합니다.
